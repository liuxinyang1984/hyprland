# Hyprland 桌面配置

通过问答逐步重建的配置仓库，不直接搬迁旧目录。

## 目录

| 路径 | 用途 |
|------|------|
| `hypr/` | Hyprland 主配置 |
| `waybar/` | 状态栏（待建） |
| `wofi/` | 启动器（待建） |
| `scripts/` | 配套脚本（待建） |

## 当前进度

1. **快捷键**（进行中）
2. 显示器 / 外观 / 输入 / 启动项
3. Waybar
4. Wofi 与脚本
5. 后续：foot、zsh 等

## 部署

将本仓库的 `hypr/` 链接或同步到 `~/.config/hypr` 后执行 `hyprctl reload`。具体 `install.sh` 稍后补充。
